## HERO DESIGN DECISIONS (locked, 2026-09-12)

- Chose "distinctive geometry signature" over rescue-the-glass / material-shader / kill-3D.
- Chose "Bright lattice" motif over "byte field" and "typographic signal".
- Glass is weak because transmission needs detail + HDRI + high resolution, all killed by
  the D-12 mobile LCP budget. Lattice inverts this: crisp + ~2 draw calls, so the budget
  stops being a design constraint.
- Fallback decision: render a STATIC SVG lattice (not blank gradient) for reduced-motion /
  no-WebGL users — a signature only motion users can see is a half-signature.
