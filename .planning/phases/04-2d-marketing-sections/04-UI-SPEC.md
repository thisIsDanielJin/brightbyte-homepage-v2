## Typography

Single typeface: Plus Jakarta Sans. Weight-driven hierarchy (no secondary typeface). Scale from `styles/tokens.css`.

| Role | CSS Token | Rendered Size | Weight | Line Height | Used In |
|------|-----------|--------------|--------|-------------|---------|
| Label / UI chrome | `--text-sm` | 14px | 500 (medium) | 1.4 | Nav links, footer links, form labels, pricing tier labels, badges |
| Body | `--text-base` | 16px | 400 (regular) | 1.6 | Services description, testimonial quotes, about body, contact form helper text, legal page body, pricing `includes` list |
| Subheading | `--text-2xl` | 24px | 600 (semibold) | 1.3 | Section eyebrow + primary section headings on mobile, pricing tier title, work card title, testimonial author name |
| Display — mobile | `--text-4xl` | 32px | 700 (bold) | 1.15 | Hero headline on 375px viewport |
| Display — desktop | `--text-5xl` | 48px | 700 (bold) | 1.1 | Hero headline on 1440px viewport; section headings on 1440px scale up to `text-4xl` (32px) |

Declared weights: **400** (regular), **600** (semibold), **700** (bold). Maximum 3 weights — justification: bold is reserved for hero/display only; regular + semibold cover all body and heading needs; bold prevents the heading from feeling too restrained for the hero's one "wow" moment.

> Source: CONTEXT.md (Claude's Discretion: "exact typographic scale per section bounded by Phase 1 tokens"), `styles/tokens.css` type scale. The `--text-4xl` value in tokens.css is 2rem/32px and `--text-5xl` is 3rem/48px — mapping is exact.

## Color

### Accent Reserved-For List (explicit — not "all interactive elements")

Accent (`--color-accent`, #1C39BB, 8.93:1 on white) is reserved ONLY for:
1. Primary CTA buttons (hero CTA, contact form submit button) — background fill
2. Active / current nav link indicator (underline only, not background)
3. Focus-visible ring on all interactive elements (`ring-accent`)
4. In-page anchor links that appear within body copy (e.g. legal page cross-references)

Accent is NOT used for: card borders, section dividers, hover states on text links (hover uses `--color-primary`), pricing tier decoration, testimonial metric callouts (those use `--color-primary` at larger weight).

## Motion Contract (SEC-11, D-14)

**Library:** `motion/react` (import from `motion/react`, not `framer-motion`)

**Pattern: Whisper-quiet entrance fade only.**

All animated section wrappers use `<motion.section>` or a `<motion.div>` wrapper with:
```
initial={{ opacity: 0, y: 10 }}
whileInView={{ opacity: 1, y: 0 }}
viewport={{ once: true, amount: 0.15 }}
transition={{ duration: 0.5, ease: [0.0, 0.0, 0.2, 1] }}
```

Where:
- `y: 10` = 10px upward translate (within D-14's 8–12px spec)
- `duration: 0.5` = 500ms = `--duration-entrance` token value
- `ease: [0.0, 0.0, 0.2, 1]` = `--ease-out` cubic-bezier as array (motion/react format)
- `once: true` = plays once on entry, never replays on scroll back

**Reduced motion:** `globals.css` already applies `animation-duration: 0.01ms !important` and `transition-duration: 0.01ms !important` under `prefers-reduced-motion: reduce`. This covers CSS transitions. For `motion/react`, additionally check `useReducedMotion()` hook and pass `{ duration: 0 }` transition when true. Alternatively, use `motion`'s built-in `prefers-reduced-motion` support via `<LazyMotion>` — executor to pick preferred approach.

**What does NOT animate:**
- Header sticky transition (CSS `transition` only, no motion/react)
- Work card hover lift (CSS `transition` only)
- Button hover states (CSS `transition` only)
- Logo, footer, legal pages — no entrance animation

**Explicitly forbidden (D-14):** parallax, scale transforms, stagger sequences, continuous motion, loop animations.

## Interaction & State Contracts

### Focus-Visible (QA-03)

All interactive elements must show `:focus-visible` — never `:focus` alone (prevents focus rings on mouse click).

**Standard focus ring:** `ring-2 ring-accent ring-offset-2` applied via Tailwind on all `<a>`, `<button>`, `<input>`, `<textarea>`, `<select>` elements.

Add to `globals.css`:
```css
@layer base {
  :focus-visible {
    outline: none;
    ring-width: 2px;
    ring-color: var(--color-accent);
    ring-offset-width: 2px;
```
