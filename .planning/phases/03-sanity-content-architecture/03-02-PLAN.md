# Plan 03-02 — Expansion: full schema set + singleton + image builder + query layer

## Goal

With the tracer proven (Plan 01), add the remaining four document types (`project`, `testimonial`, `seoPage`, `siteSettings`), enroll all five types in document-internationalization, enforce the `siteSettings` singleton via the structure builder, add the `@sanity/image-url` builder, and complete the centralized `$locale`-parameterized typed query set that Phase 4 imports. Delivers CMS-01 (all five schema types + doc-i18n) and extends CMS-03 (full typed query layer).

## Reversibility note

Two `costly`/one-way decisions get a `checkpoint:decision`: D-07 (siteSettings singleton — enforced in structure builder + pinned doc id) and D-08 (the exact doc-i18n type SET — adding/removing a paired type later means schema + query changes). D-11 (per-locale slugs) is embedded in the slugged types; it is costly but is confirmed as part of the D-08 gate to avoid a separate stop.

## Artifacts this phase produces (Plan 02 subset)

- **Files:** `sanity/schemaTypes/project.ts`, `sanity/schemaTypes/testimonial.ts`, `sanity/schemaTypes/seoPage.ts`, `sanity/schemaTypes/siteSettings.ts`, `lib/sanity/image.ts`
- **Exports:** `project`, `testimonial`, `seoPage`, `siteSettings` (schema types); `urlFor` (lib/sanity/image.ts); extended `schemaTypes` array; extended query set in queries.ts: `PROJECTS_QUERY`+`getProjects(locale)`, `PROJECT_BY_SLUG_QUERY`+`getProjectBySlug(locale, slug)`, `TESTIMONIALS_QUERY`+`getTestimonials(locale)`, `SEO_PAGES_QUERY`+`getSeoPages(locale)`, `SEO_PAGE_BY_SLUG_QUERY`+`getSeoPageBySlug(locale, slug)`, `SITE_SETTINGS_QUERY`+`getSiteSettings(locale)`
- **Fixed doc id:** `siteSettings` (DE base singleton id, D-07)
- **Inline outcome fields on testimonial:** `outcomeValue`, `outcomeLabel` (D-06 — inline, not a shared object, per PATTERNS simpler-approach note)

## must_haves

truths:
  - All five document types (project, testimonial, service, seoPage, siteSettings) exist and are enrolled in `@sanity/document-internationalization` with DE/EN pairs (CMS-01).
  - `siteSettings` is a structure-builder-enforced singleton (fixed DE id, disabled create/delete), queried via `language == $locale`.
  - `testimonial` carries a separate, queryable outcome metric (outcomeValue/outcomeLabel) — D-06.
  - `project`/`seoPage` use per-locale non-shared slugs — D-11.
  - `lib/sanity/queries.ts` is a complete `defineQuery`-typed `$locale`-parameterized set; `lib/sanity/image.ts` exports `urlFor`.
prohibitions:
  - No second `createClient` (image builder + all queries import the single client).
  - No un-`defineQuery`'d `client.fetch('...')` string in queries.ts.
  - No Portable Text on short string fields (only seoPage.body + any genuine long-form) — D-04.
  - No parallel content store; no `tailwind.config.js`; no CJS.
