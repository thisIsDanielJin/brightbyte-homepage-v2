# Plan 03-01 — Tracer: end-to-end locale-filtered typed Sanity read

## Goal

Prove the entire Sanity pipeline works end-to-end on ONE vertical slice before expanding: local Node ≥22.12 → Sanity ecosystem installed → embedded Studio mounts at `/studio` → ONE document-internationalized schema type (`service`) loads in Studio with a `language` field → ONE `$locale`-filtered typed GROQ query in `lib/sanity/queries.ts` reads it through a single `stega:false` client → `sanity typegen` produces typed results → `npm run build` is green with no stega corruption. Expansion (remaining types, content, guards) happens in Waves 2–3 only after this slice is verified.

## Reversibility note

This plan implements four `costly`/one-way decisions — each gets a `checkpoint:decision` before its task: D-12 (Node upgrade — toolchain-wide), D-01 (embedded Studio route lives inside the Next app), D-10 (`$locale`-filter query contract Phase 4 imports), and the D-05 structured `price` object shape.

## Threat model (ASVS L1, block-on: high)

<threat_model>
- **T-03-01 — Draft/unpublished content leaks into the public build.** STRIDE: Information Disclosure. Asset: Content Lake read path. Mitigation: single client sets `perspective:'published'` (Pattern 2). Enforced in task 03-01-10 (client.ts) + build in 03-01-11. Severity: medium — mitigated.
- **T-03-02 — stega tokens corrupt SEO titles/slugs.** STRIDE: Tampering (data integrity). Asset: `generateMetadata`/`generateStaticParams` output. Mitigation: `stega:false` on the single client. Enforced in 03-01-10; build check in 03-01-11 (automated guard lands in Plan 03). Severity: high → mitigated by the invariant (no unmitigated high remains).
- **T-03-03 — Write/deploy token shipped in the browser bundle.** STRIDE: Information Disclosure / Elevation. Asset: Sanity credentials. Mitigation: read client is tokenless for published reads; `NEXT_PUBLIC_*` holds only public projectId/dataset; any import token is local-env + gitignored. Enforced in 03-01-03 (env + gitignore + grep). Severity: high → mitigated.
- **T-03-04 — `/studio` treated as an unauthenticated content-mutation surface.** STRIDE: Elevation of Privilege. Asset: content dataset. Mitigation: Studio is gated by Sanity's own auth (D-02); the route renders the client Studio app only — no server mutation endpoint is added; Studio metadata sets robots noindex. Enforced in 03-01-08. Severity: medium — mitigated (auth is Sanity-managed; do not roll custom auth).
- No unmitigated **high** threats remain — plan is ready.
</threat_model>
