## Spacing Scale

Declared values — 8-point base, multiples of 4. Section-level values extended to 96 and 128 for generous editorial breathing room (D-03: balanced & confident posture).

All values expressed as CSS custom properties within Tailwind v4 `@theme {}` in `styles/tokens.css`.

| Token | CSS Variable | Value | Usage |
|-------|-------------|-------|-------|

## Typography

**Typeface:** Plus Jakarta Sans (Google Fonts variable font, axes: wght 200–800)

**Rationale for Plus Jakarta Sans (D-10 — Claude's discretion):**
The direction is "modern, slightly characterful grotesk" — not plain/neutral (Inter, Helvetica), not brutal (Syne), not editorial-serif (Fraunces). Plus Jakarta Sans delivers a distinctly contemporary grotesk with subtle aperture personality at display sizes, excellent legibility at body sizes, a wide weight range suitable for weight-only typographic hierarchy, and a Google Fonts license (free, no FOUT risk with `display: swap`). It reads as designed — not default — which is the "senior/principal designer" signal needed without intimidating SMB clients. It directly counters v1's 3-font failure by providing full personality range within a single family.

**Self-hosted preferred** over Google Fonts CDN (performance rule: zero third-party requests at LCP paint). Use `next/font/google` with `subsets: ['latin']` to inline font-face declarations at build time.

| Role | Size | CSS Var | Weight | Weight Name | Line Height | Letter Spacing |
|------|------|---------|--------|-------------|-------------|----------------|
| Label | 14px | `--text-sm` | 500 | Medium | 1.4 | 0.02em |
| Body | 16px | `--text-base` | 400 | Regular | 1.6 | 0 |
| Subheading | 24px | `--text-2xl` | 600 | Semibold | 1.3 | -0.01em |
| Display | 48px | `--text-5xl` | 700 | Bold | 1.1 | -0.02em |

**Weight rule (2 weights max — D-09):** The system uses two primary weights — 400 (Regular) for body copy and 700 (Bold) for display headings. 500 (Medium) is permitted for labels and UI chrome only (not narrative copy). 600 (Semibold) bridges subheadings. In practice: narrative text = 400, subheadings = 600, display headings = 700.

**Responsive type:** Display size scales down to 32px (`--text-4xl`) at mobile (< 640px). Subheading stays at 24px. Body/label unchanged.

## Color

**Strategy:** Light-first (D-05). True-neutral gray ramp — no warm tint (D-02). Single accent: Persian blue (D-06). All remaining chromatic interest via photography (D-08).

All values expressed as CSS custom properties in `@theme {}`. Zero raw hex values permitted in any component file (IDENT-01 hard rule).

### Base Palette

| Role | CSS Variable | Hex | Usage |
|------|-------------|-----|-------|
| Surface (60%) | `--color-surface` | `#FFFFFF` | Page background, card surfaces |
| Surface Subtle | `--color-surface-subtle` | `#FAFAFA` | Alternate section backgrounds |
| Surface Muted | `--color-surface-muted` | `#F4F4F5` | Input backgrounds, code blocks |
| Border | `--color-border` | `#E4E4E7` | Dividers, input borders, card outlines |
| Text Muted | `--color-text-muted` | `#A1A1AA` | Captions, placeholders, disabled |
| Text Secondary | `--color-text-secondary` | `#52525B` | Secondary body, metadata, dates |
| Text Primary | `--color-text-primary` | `#18181B` | Primary body, headings, all narrative copy |
| Accent | `--color-accent` | `#1C39BB` | See reserved list below |
| Accent Hover | `--color-accent-hover` | `#1630A0` | Accent element hover state |
| Destructive | `--color-destructive` | `#DC2626` | Form errors, destructive confirmations only |

**Dominant (60%):** `#FFFFFF` / `#FAFAFA` — page background and all section surfaces
**Secondary (30%):** `#F4F4F5` / `#E4E4E7` — alternate section tints, input backgrounds, borders, dividers
**Accent (10%):** `#1C39BB` — reserved exclusively for the elements listed below

### Accent Reserved For (explicit list — D-07: sparingly / functional)

1. Primary CTA button — background fill
2. Hyperlinks in body copy — text color
3. Focus rings — `outline-color` on all focusable elements
4. Active navigation item — underline or indicator
5. Form field border on `:focus` state

Accent is NOT used for: decorative shapes, section backgrounds, card borders, secondary buttons, hover highlights on neutral elements, icon fills.

### Dark Surface (for hero/footer moments — D-11 wordmark must render on both)

| Role | CSS Variable | Hex | Usage |
|------|-------------|-----|-------|
| Surface Dark | `--color-surface-dark` | `#0F0F10` | Hero section, footer — near-black |
| Text On Dark | `--color-text-on-dark` | `#F4F4F5` | Primary text on dark surfaces |
| Text Muted On Dark | `--color-text-muted-on-dark` | `#A1A1AA` | Secondary text on dark surfaces |

### WCAG AA Contrast Pre-verification (must be confirmed before Phase 4 component work)

| Pair | Hex on Hex | Required Ratio | Verdict |
|------|-----------|----------------|---------|
| Text Primary on Surface | `#18181B` on `#FFFFFF` | 4.5:1 (normal text) | PASS — ~19.1:1 |
| Text Primary on Surface Subtle | `#18181B` on `#FAFAFA` | 4.5:1 | PASS — ~18.6:1 |
| Accent on Surface (body text size) | `#1C39BB` on `#FFFFFF` | 4.5:1 | PASS — ~5.8:1 |
| Accent on Surface (large text) | `#1C39BB` on `#FFFFFF` | 3:1 | PASS — ~5.8:1 |
| Text On Dark on Surface Dark | `#F4F4F5` on `#0F0F10` | 4.5:1 | PASS — ~18.1:1 |
| Text Muted on Surface | `#A1A1AA` on `#FFFFFF` | 4.5:1 | FAIL — ~2.4:1 — muted text is decorative/non-essential only; never used for readable body copy |
| Text Secondary on Surface | `#52525B` on `#FFFFFF` | 4.5:1 | PASS — ~7.0:1 |

**Note on Text Muted:** `#A1A1AA` on white fails AA for normal text. This token is restricted to placeholders, captions, and disabled states — never for meaningful body or label copy. Any copy that must be read uses `--color-text-secondary` or `--color-text-primary`.

## Motion Tokens

Phase 1 establishes all motion easing and duration tokens in `@theme {}` so Phase 4's `motion/react` animations consume named values, not magic numbers.

| Token | CSS Variable | Value | Usage |
|-------|-------------|-------|-------|
| Ease Entrance | `--ease-out` | `cubic-bezier(0.0, 0.0, 0.2, 1)` | Elements arriving: fade-in, slide-up on scroll |
| Ease Standard | `--ease-standard` | `cubic-bezier(0.4, 0.0, 0.2, 1)` | State transitions, hover, focus |
| Ease Exit | `--ease-in` | `cubic-bezier(0.4, 0.0, 1, 1)` | Elements leaving |
| Duration Micro | `--duration-micro` | 150ms | Hover color/opacity changes |
| Duration Short | `--duration-short` | 200ms | Button state changes, link underlines |
| Duration Standard | `--duration-standard` | 300ms | Card hover lifts, nav transitions |
| Duration Entrance | `--duration-entrance` | 500ms | Section entrance animations (viewport-triggered) |

`prefers-reduced-motion`: All duration tokens resolve to `0ms` when the media query fires. Implement via:
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## Token File Contract

The canonical output of Phase 1 is `styles/tokens.css` containing a single Tailwind v4 `@theme {}` block.

**Hard rules for the token file (IDENT-01):**
1. Every palette value, type scale value, spacing value, and motion value used anywhere in the site lives here and only here
2. Zero raw hex values in any component file — use `var(--color-*)` utilities only
3. Zero `text-gray-*`, `bg-gray-*`, or other Tailwind default color utilities in component files — all colors consumed via named semantic tokens
4. The file is the only `@theme` block in the project — no inline `@theme` overrides in component files

**Token naming convention (Tailwind v4 CSS variable → utility mapping):**
```css
@theme {
  /* Colors */
  --color-surface: #FFFFFF;
  --color-accent: #1C39BB;
  /* ... */

  /* Typography */
  --font-sans: 'Plus Jakarta Sans', system-ui, sans-serif;
  --text-sm: 0.875rem;    /* 14px */
  --text-base: 1rem;      /* 16px */
  --text-2xl: 1.5rem;     /* 24px */
  --text-5xl: 3rem;       /* 48px */

  /* Spacing */
  --spacing-1: 0.25rem;   /* 4px */
  /* ... */

  /* Motion */
  --ease-out: cubic-bezier(0.0, 0.0, 0.2, 1);
  --duration-entrance: 500ms;
}
```
