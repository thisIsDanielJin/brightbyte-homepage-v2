# BrightByte Berlin — Brand Voice Guide

**In one sentence:** Plain, warm, direct — speaks to a florist as a person, credibility through facts.

---

## Rules

| Rule | Specification |
|------|---------------|
| **Tone** | Plain, warm, direct. Not agency-formal. Speaks to a florist or tradesperson as a person, not a client. |
| **Language register** | German-first (DE canonical). English mirrors the register exactly — not a formal translation. |
| **Sentence length** | Maximum 2 clauses per sentence. One idea per sentence. |
| **Forbidden words (DE)** | innovativ, maßgeschneidert, ganzheitlich, Lösung, Synergien, state-of-the-art |
| **Forbidden words (EN)** | innovative, bespoke, tailored, holistic, solution, cutting-edge |
| **Credibility vehicle** | Facts only — fixed price, code ownership, 24h reply. Never agency phrasing. |
| **Headlines** | Declarative benefit, not clever. "Ihre Website in 4 Wochen. Festpreis." — not "Wir bringen Ihre Idee zum Leben." |
| **CTAs** | Short, action-verb first, benefit-adjacent. Never: submit, send, click here. |

---

## Approved Copy Elements

| Element | DE Copy | EN Copy |
|---------|---------|---------|
| Primary CTA (contact) | Projekt anfragen | Start a project |
| Primary CTA (pricing) | Preise ansehen | See pricing |
| Nav CTA (header) | Kontakt | Contact |
| Empty state (no projects) | Projekte kommen bald. | Projects coming soon. |
| Form success | Nachricht erhalten. Ich melde mich innerhalb von 24 Stunden. | Message received. I'll reply within 24 hours. |
| Form error (validation) | Bitte prüfe deine Eingaben. | Please check your entries. |
| Form error (send failure) | Senden fehlgeschlagen. Versuch es nochmal oder schreib direkt an hello@brightbyte-berlin.com. | Sending failed. Try again or email hello@brightbyte-berlin.com directly. |

---

## Usage Notes

- All v2 copy is written against this guide before being added to components or Sanity content.
- When in doubt between two phrasings, choose the shorter one.
- Photography carries all emotional warmth — copy stays factual and calm.
- The forbidden-word lists apply in both headline and body copy. Run a grep check before finalising any section.
